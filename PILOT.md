# Next Level: Pilot preparation v0.8

Planning status, 25 October 2026. No partner, response deadline, recruitment or live consultation is committed by this document.

## Question

Can people navigate a specific participation process more independently and assess institutional replies better with the additional Next Level support than with existing process information alone?

## Scope and partner functions

Select one bounded case with genuine remaining scope for influence. A public institution owns the response and processing capacity. A local education or community organisation supports access and learning. Initial recruitment should focus on adults with little experience of this particular process; language or residency status alone must not be used as a proxy for support needs.

Before starting, identify the decision-maker, what can change, eligibility, deadline, alternative access routes, support arrangements, review criteria and limits to publication. If no live decision can be influenced or no office accepts responsibility for replies, run an educational simulation only.

## Concrete preparation record

Complete these fields with the responsible institution before recruiting:

| Field | Required decision |
| --- | --- |
| Case and official source | Topic, current source URL, version and date |
| Scope for influence | Open question, fixed constraints and final decision-maker |
| Access | Eligibility, languages, assisted and offline routes |
| Contributions | Official channel, submission deadline and receipt arrangements |
| Replies | Responsible office, agreed response window, update route if delayed |
| Public records | What can be published, consent and permitted redactions |
| Resources | Staff time, facilitation, translation and follow-up capacity |
| Evaluation | Recruitment, comparison conditions, delayed task and analysis plan |
| Data handling | Minimal fields, purpose, access, retention and deletion |
| Organisational change | Owner of improvements and later review date |

No general legal entitlement to a particular response format or deadline is implied. Confirm process-specific requirements with the institution.

## Phased evaluation

1. Formative access review: observe actual barriers with intended participants and facilitators. Correct content and accessibility issues before live use.
2. Feasibility phase: estimate recruitment, task difficulty, support needed and institutional workload. Set sample size and the comparison method after this phase.
3. Comparison: assess existing process information alongside the additional learning support. Record assistance, baseline experience and alternative explanations. A small convenience sample is suitable for usability findings, not a general effectiveness claim.
4. Delayed transfer: use a different case without the original answer choices. Agree the interval and scoring criteria in advance.
5. Institutional review: inspect agreed replies, reasons, dates, evidence and unresolved issues. Record one resulting process change, its owner and whether later review supports improvement.

## Outcomes to examine

People: independently find the right route; explain deadline, eligibility and scope; develop their own position; identify what a reply establishes; ask an appropriate question; repeat with a different case after a delay.

Institution: timely acknowledgement and substantive response where agreed; comprehensible reasons; dated records; transparent delays and rejected proposals; processing effort; documented changes and later review.

Do not score political agreement, approval of the institution, willingness to submit more contributions or trust as prerequisites for success. Disagreement, justified distrust and informed non-participation are valid outcomes. The learning exercise must not become an admission test.

## Positioning and evidence

Feedback, implementation tracking and democracy education are established fields. The specialisation proposed here is case-specific learning support combined with critical reply assessment and examination of institutional conditions. It is not a demonstrated exclusive capability.
